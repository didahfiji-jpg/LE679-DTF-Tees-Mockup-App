# DTF Tees Mockup App

Desktop edition of Limited Editions 679 Studios' DTF Tees Mockup App.

This repository contains the existing HTML mockup editor and a Python/pywebview Windows desktop wrapper. GitHub Actions builds a Windows EXE with PyInstaller.

## Build

Open **Actions → Build Windows EXE** and download the artifact ZIP from a successful workflow run. Extract `DTF Tees Mockup App.exe`.

Requires Microsoft Edge WebView2 Runtime on Windows. Online Google Fonts require internet; core mockup tools are otherwise designed to run offline.
